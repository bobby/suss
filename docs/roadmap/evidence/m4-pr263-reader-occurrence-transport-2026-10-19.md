extent before cloning the authenticated source node; that clone preserves
original prefix slots before appending indexing metadata. Graph uses one owned

metadata. The earlier candidate joined separate raw/enriched keys by content
equality; independent review rejected that inference, and it was removed before
integration. The original source-origin API remains unchanged.

without global same-label interning. Raw source keys and metadata values keep
their existing full Form routes. FormBridge carries the constructor through
private synthetic-map tasks, preserving child/base-before-metadata construction
order and original typed metering errors. Carrier/supplied-slot extents are checked
before indexing; new buffers and selectors are charged using their actual layout.
Compile-time queue-layout assertions require the old slot extent to remain valid.
